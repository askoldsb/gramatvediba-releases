# Grāmatvedība — izlaidumi

Privātas personīgo finanšu programmas **Grāmatvedība** izlaidumi un automātiskās atjaunināšanas manifests.
Šeit ir tikai programma, bez lietotāja datiem. Kods glabājas privātā repozitorijā.

- Mac uzstādītājs: [installers/](installers) → atarhivē un atver „Grāmatvedība — uzstādīt.app”
- `latest.json` — manifests, ko programma lasa (kanāli `stable` un `test`)
- `releases/` — pēdējo versiju arhīvi
